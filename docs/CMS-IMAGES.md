# Αλλαγή φωτογραφιών από το Pages CMS

1. Άνοιξε https://app.pagescms.org/ και επίλεξε το repository `stelios-sioulas/stelios-sioulas.github.io` και το branch `main`, αφού ενσωματωθεί η αναβάθμιση.
2. Άνοιξε **ΦΩΤΟΓΡΑΦΙΕΣ / IMAGES**. Κάθε πεδίο δείχνει την τωρινή εικόνα του αντίστοιχου σημείου.
3. Επίλεξε υπάρχουσα εικόνα ή ανέβασε JPG, JPEG, PNG, WebP ή AVIF. Προτίμησε WebP έως 2 MB, με παρόμοιες αναλογίες με την αρχική εικόνα. Το CMS δημιουργεί ασφαλές όνομα αρχείου.
4. Πάτησε **Save**, περίμενε να ολοκληρωθεί η δημοσίευση στο GitHub Pages και έλεγξε EN/EL, desktop και κινητό. Η ίδια επιλογή ενημερώνει όλες τις αντίστοιχες εμφανίσεις.

Οι διαστάσεις, τα κάδρα, οι σκιάσεις, οι χρωματισμοί και η διάταξη ελέγχονται από το υπάρχον design. Αυτή η αναβάθμιση αλλάζει την εικόνα μέσα στο ίδιο κάδρο. Άφησε το πεδίο κενό για επαναφορά στην αρχική εικόνα. Αν ένα αρχείο λείπει ή δεν φορτώνει, παραμένει η αρχική φωτογραφία.

Η εικόνα MEDIA χρησιμοποιείται επίσης στο φόντο του PRESS KIT. Για τις αφίσες συγκεκριμένων εμφανίσεων χρησιμοποίησε **LIVE**, και για τη φωτογραφία που κατεβάζουν τα ΜΜΕ χρησιμοποίησε **PRESS KIT**. Οι διακοσμητικές φωτογραφίες φόντου δεν αλλάζουν αυτόματα τα σταθερά social-preview/SEO images, το logo ή το favicon.

Αντικατάσταση εικόνας: ανέβασε νέο αρχείο, επίλεξέ το και αποθήκευσε πριν διαγράψεις την παλιά εικόνα. Μη διαγράψεις τα αρχικά assets, γιατί χρησιμοποιούνται ως εφεδρικές εικόνες. Έλεγξε ότι έχεις δικαίωμα χρήσης και αφαίρεσε ιδιωτικά EXIF/GPS δεδομένα πριν ανεβάσεις φωτογραφίες. Το site είναι στατικό και δεν μετατρέπει αυτόματα τις νέες εικόνες.

Για την αρχική δοκιμή πριν την ενσωμάτωση, επίλεξε το branch `cms-photo-management` αντί για `main`. Οι αλλαγές σε αυτό το branch δεν δημοσιεύονται στο κανονικό site.
